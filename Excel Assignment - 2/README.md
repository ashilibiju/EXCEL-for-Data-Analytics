Assignment 2: Data Cleaning and Transformation

Overview

Cleaned and transformed a product dataset using Microsoft Excel to improve data quality and consistency.

Tasks Performed

- Missing Values: Filled missing prices with estimated values and assigned missing product categories.
- Data Standardization: Standardized product names and corrected category typos.
- Duplicate Removal: Removed duplicate records, reducing 34 rows to 31 unique rows.
- Data Extraction: Extracted manufacturing dates and country codes from Product IDs.
- Data Transformation: Combined brand and product names into a single column.
- Formatting: Applied USD currency, date formatting, and conditional formatting.

Tools Used

- Microsoft Excel

Skills Learned

Data cleaning, data transformation, handling missing values, duplicate removal, and data formatting.
